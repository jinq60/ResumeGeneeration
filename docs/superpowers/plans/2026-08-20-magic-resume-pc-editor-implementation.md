# PC 简历编辑器实现计划

> 范围：仅前端编辑器布局与交互；保留工作台侧边栏、当前简历数据模型、自动保存、历史记录、预览与导出入口。

## 1. 先固定可回归行为

- 为模块栏新增组件测试：选中、显隐、删除、拖拽排序、主题与排版入口。
- 为基本信息表单补测试：姓名输入向上同步为新的 profile section。
- 先运行测试确认当前实现不能满足这些行为。

## 2. 重建桌面编辑器骨架

- 新增 `EditorModuleRail.vue`，实现模块卡片、排序交互、添加模块、主题色和排版入口。
- 新增 `EditorHeader.vue`，只负责标题、保存状态、撤销/重做、预览和导出事件。
- 新增 `EditorFormPanel.vue` 和 `EditorPreviewStage.vue`，分别承载模块表单和 A4 预览/底部工具条/右侧 Dock。
- 在 `EditorView.vue` 中将现有事件和状态接到新组件；以 `activeSectionId` 选中具体模块，避免同类型自定义模块相互抢占。

## 3. 补齐基本信息与视觉密度

- 在 `ProfileForm.vue` 的基础字段首行加入姓名，保持现有 `useSectionSync` 更新链路。
- 将头像与布局选择放到资料区域，继续复用现有上传与表单数据。
- 用局部 SCSS 实现暖白、细边框、高密度模块卡、浅灰预览画布和 A4 阴影；仅优化 1024px 及以上桌面视图。

## 4. 验证与交付

- 运行新增组件测试、全量 Vitest 与生产构建。
- 用本地浏览器在 1280px、1440px、1920px 宽度检查工作台侧栏仍存在、三栏不溢出、A4 可缩放。
- 不修改后端接口、数据库或导出服务；记录既有构建警告与无法在无后端条件下验证的实时 iframe 项目。
