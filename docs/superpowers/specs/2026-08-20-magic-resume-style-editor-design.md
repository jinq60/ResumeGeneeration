# PC 简历编辑器（魔方简历风格）设计

## 目标

在保留现有工作台左侧导航、简历数据模型、自动保存、实时预览与导出入口的前提下，将 PC 端简历编辑器重构为与魔方简历截图一致的桌面工作台体验。实现只包含前端代码；不新增或修改后端接口、数据库迁移与 Java 服务。

## 约束与范围

### 本次包含

- 仅覆盖 1024px–2560px 的桌面浏览器与笔记本屏幕；不提供移动端专门布局。
- 保留 `WorkbenchLayout` 和 `WorkbenchSidebar`，编辑器只重构工作台主内容区。
- 编辑器内部采用“模块栏 / 表单栏 / A4 预览栏”三栏布局。
- 还原魔方简历风格的顶栏、模块卡片、字段行、主题与排版区、悬浮预览工具与右侧快捷工具。
- 保留并接入现有模块拖拽排序、显隐、删除、新增、自定义字段、主题/排版、缩放、分页、撤销/重做、草稿、自动保存、AI 入口、模板切换与导出入口。
- 修复 `ProfileForm` 中缺少姓名输入的问题，并把基本信息字段统一为可排序、可显隐的行式编辑体验。
- 为新增的模块栏与基础信息行为补 Vitest 测试，并用 1440px 与 1280px 视口做可视化检查。

### 本次不包含

- 后端接口、数据库、PDF/Word 渲染服务或鉴权逻辑的改动。
- 新的 AI 能力、模板数据、文件上传协议或业务字段。
- 手机、平板及窄屏双栏/单栏体验。
- 从 `JOYCEQL/magic-resume` 复制源代码、品牌名称、图片、字体或其他素材；只独立实现其可见的布局与交互范式。

## 视觉方向

### 页面结构

```text
现有工作台侧栏 | 编辑器顶栏──────────────────────────────────────────────
               | 模块栏       | 当前模块表单                  | A4 预览画布
               | 布局/模块卡片 | 字段行、卡片、局部设置          | 浮动工具、右侧工具
               | 主题与排版    |                              |
```

工作台侧栏保持原样。`EditorView` 使用负边距或专用页面类占用工作台剩余空间，整体高度与视口一致。顶栏高度为 64px：左边显示简历标题、重命名与保存状态，右边放置面板收起、撤销、重做、预览与导出操作。

编辑器主体三栏如下：

1. 模块栏使用 260–320px 的自适应宽度，展示“布局”标题、模块卡片、添加模块按钮、主题色与排版入口。模块卡片的选中状态为黑色细描边，未选中状态为淡灰描边。每张卡片包含拖拽把手、图标、名称、显隐和删除操作。
2. 表单栏使用 360–560px 的自适应宽度。顶部以图标、模块标题和圆角容器建立层级；基本信息采用“拖拽把手 / 图标 / 标签 / 输入控件 / 显隐或删除”的字段行。其余模块复用相同的卡片、行高、控制按钮和间距规则。
3. 预览栏占据剩余空间，使用浅灰画布与居中白色 A4 页面。A4 页面保留现有 iframe 实时预览；底部悬浮圆角工具条承载缩放、页码和既有操作，右侧垂直工具条作为模板、排版、预览、AI 等现有入口的桌面快捷方式。

### 视觉令牌

| 名称 | 值 | 用途 |
| --- | --- | --- |
| 画布暖白 | `#f6f6f3` | 编辑器与模块栏背景 |
| 面板白 | `#ffffff` | 顶栏、模块卡与表单面板 |
| 预览灰 | `#eef0f1` | A4 预览画布 |
| 墨黑 | `#20201d` | 主文字、选中描边、导出按钮 |
| 边框灰 | `#e4e4e0` | 面板与字段分隔 |
| 辅助文字 | `#75756f` | 次要标签与图标 |
| 保存绿 | `#18a87a` | 已保存状态 |

正文使用系统无衬线中文字体栈；仅简历标题允许使用现有的衬线标题字体。圆角限定为 8px、12px、14px 三档，避免混用大圆角。交互反馈为 160–180ms 的颜色、描边和阴影过渡；遵从用户的减少动画偏好。

### PC 自适应规则

- `>= 1920px`：模块栏 300px，表单栏约 520px；A4 以 100% 显示或在空间不足时自动适配。
- `1280px–1919px`：模块栏 250–280px，表单栏 380–460px；A4 始终按预览栏可用宽高自动缩放，不溢出画布。
- `1024px–1279px`：保留三栏，模块栏不小于 230px，表单栏不小于 340px，A4 保持自动适配。低于 1024px 的布局不在此次验收范围内。

## 前端架构

`EditorView.vue` 继续负责路由参数、简历加载、历史记录、草稿、自动保存、对话框状态和 API 调用。它仍以单个 `resume` 响应式对象作为编辑数据源，禁止为布局组件创建第二份可写的简历副本。

建议拆分的组件边界：

| 组件 | 职责 | 数据边界 |
| --- | --- | --- |
| `EditorHeader.vue` | 标题、重命名触发、保存状态、撤销/重做、预览与导出 | 接收展示状态与回调，不持有 `Resume` 副本 |
| `EditorModuleRail.vue` | 模块卡片、排序、显隐、删除、添加模块、布局入口 | 接收 `Section[]`，通过 emit 返回意图 |
| `EditorFormPanel.vue` | 当前模块标题与现有表单组件的统一容器 | 接收活动模块和既有 `Resume`，沿用现有更新事件 |
| `EditorPreviewStage.vue` | A4 画布、iframe 预览、缩放、页码、底部与右侧工具 | 接收只读简历与视图状态，通过 emit 请求改变视图 |
| `ProfileForm.vue` | 基本信息的字段行、头像、可选字段和自定义字段 | 继续通过 `useSectionSync` 返回新的 sections |

如果提取组件会与当前未提交的用户改动产生冲突，可先在 `EditorView.vue` 内完成视觉布局，再只提取无状态展示组件。组件拆分不能改变已存在的接口契约。

## 数据流与交互

1. 编辑器仍通过 `resumeApi.get(id)` 加载 `Resume`，写入 `EditorView` 的 `resume` 引用。
2. 表单更新、模块排序、显隐、删除与添加都生成新的 `sections` 数组，并走现有 `handleSectionsUpdate` / `applyResumeChange` 路径。
3. `useResumeHistory` 记录用户可撤销的本地变化；`useResumeDraft` 持久化草稿；`useAutoSave` 继续在既有防抖时间后调用当前更新接口。
4. `ResumePreview` 继续根据 `Resume` 生成 iframe 内容。缩放仅影响编辑器画布，不改变预览 HTML、PDF 与 Word 的最终尺寸。
5. 主题色、字体、行高、页边距和模块间距继续复用 `renderSettings` 及已有设置对话框。右侧/悬浮工具只改变已有前端状态或打开既有对话框，不创建新后端依赖。
6. 保存失败保持现有可见状态和重试路径；布局组件不吞掉异常，也不在组件内部直接发 Axios 请求。

## 可访问性与交互细节

- 每个图标按钮提供 `title` 和 `aria-label`；删除动作要求明确点击，并保留现有安全行为。
- 非选中的模块卡片可以通过键盘聚焦与回车选中；拖拽失败时不改变模块顺序。
- 隐藏的模块卡片仍标明状态，且个人信息模块保持不可删除/不可隐藏。
- 所有文本以 Vue 插值渲染，不通过模板拼接用户输入的 HTML。

## 测试与验收

### 自动化测试

- 新增 `EditorModuleRail` 组件测试：选中模块、请求删除、请求显隐与拖拽顺序事件。
- 新增或扩展 `ProfileForm` 测试：姓名输入存在并通过现有 `update` 事件同步至 profile section。
- 新增桌面编辑器壳层测试：顶栏、三栏容器和预览工具栏在 desktop 状态下渲染。
- 执行 `npm run test:unit -- --run`、`npm run build`。

### 视觉验收

- 在 1440px 和 1280px 宽度下检查：工作台侧栏仍存在，三栏无相互覆盖，A4 页面居中，底部工具条可用，右侧工具条不遮挡页面。
- 检查基本信息模块：姓名、职位、状态、地址、生日、邮箱、电话等字段有一致的行式布局；模块栏和主题区符合截图的白底、细边框和黑色选中描边。
- 验证已存在的自动保存、撤销/重做、导出、模板和排版入口仍可被触发。

## 风险与处理

- 当前 `EditorView.vue`、`ProfileForm.vue` 与设计系统文件已有未提交改动。实现只基于当前工作区增量修改，不重置、不覆盖、也不回退这些改动。
- 三栏在 1024px 处可用空间较小。通过 CSS `clamp`、最小宽度和 A4 显示缩放保持三栏，而不引入移动端分支。
- 现有预览依赖后端 HTML。布局单测采用组件替身或已有预览组件测试，完整视觉检查在可连通本地后端时执行；若后端未运行，仍完成布局与前端构建验证。
