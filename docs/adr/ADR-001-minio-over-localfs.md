# ADR-001：对象存储采用 MinIO（兼容 S3）替代本地文件系统

## 状态

已接受（Accepted）

## 背景

PRD 与早期设计文档中，头像、PDF、模板缩略图等文件的存储方案存在两种声音：

1. **本地文件系统**：简单直接，开发成本低。
2. **对象存储**：便于扩展、CDN 接入、多机部署。

## 决策

采用 **MinIO（兼容 S3 协议）** 作为统一对象存储方案，数据库只保存文件 URL。

## 理由

1. **可扩展性**：本地文件系统在多机部署时需要共享存储或 NAS，对象存储天然支持水平扩展。
2. **CDN 友好**：对象存储可直接对接 CDN，加速头像/PDF/模板资源访问。
3. **成本可控**：MinIO 可私有化部署，无需依赖第三方云厂商。
4. **与团队技术栈一致**：团队对 S3/MinIO 使用经验丰富。
5. **数据库存储压力小**：避免 BLOB 字段，降低备份与迁移成本。

## 影响

- 所有文件上传接口必须将文件写入 MinIO，返回可访问 URL。
- 删除文件时必须同步清理对象存储中的资源。
- 开发环境需额外启动 MinIO 服务。
- 生产环境需配置 CDN 或预签名 URL。
