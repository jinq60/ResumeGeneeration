# ADR-003：P0 头像 AI 优化使用占位实现

## 状态

已接受（Accepted）

## 背景

PRD §7.4 提出头像 AI 优化需求，包括白底/蓝底/红底证件照、职业商务头像、自然清爽头像、高清修复、去除杂乱背景、提亮肤色等。真实 AI 模型需要：

- 人脸检测与关键点定位。
- 背景分割/替换。
- 图像增强（超分、美颜）。
- 模型部署与 GPU 资源。

在 P0 阶段投入真实 AI 模型会显著增加复杂度、成本和上线风险。

## 决策

P0 阶段头像优化采用 **占位实现**：

- 接口、任务状态机、数据模型按真实 AI 流程设计。
- 实际处理逻辑仅做简单缩放/居中裁剪或直接复制原图。
- P1 阶段再接入真实 AI 模型，替换 `AvatarService.optimize` 实现，保持接口契约不变。

## 理由

1. **降低 P0 风险**：避免 AI 模型稳定性影响 MVP 上线。
2. **保留产品形态**：用户可体验完整的上传 → 选择背景/风格 → 创建任务 → 查看结果流程。
3. **接口前瞻**：P1 接入真实模型时，前端无需改动。
4. **资源可控**：P0 无需 GPU 和模型服务。

## 影响

- `AvatarService.optimize` 当前为占位实现，需在 P1 重构。
- 测试用例需区分 P0 占位行为与 P1 真实行为。
- 产品侧需在 UI 中明确标注“P0 效果为占位，P1 升级真实 AI”。
