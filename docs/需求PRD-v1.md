# 简历生成工具 PRD

## 1. 产品概述

### 1.1 产品名称

智能简历生成工具

### 1.2 产品定位

本产品是一款面向学生、求职者和职场人士的在线简历生成工具。用户通过左侧表单填写个人信息、教育经历、项目经历、工作经历、主修课程、技能技术栈、自我介绍等内容，右侧实时生成简历预览，并支持一键导出 PDF。

产品同时提供头像优化功能，用户可上传头像，并根据使用场景选择白底、蓝底、红底、职业照风格、自然证件照风格等版本，由系统根据用户选择自动生成提示词并调用图片优化能力，最终将处理后的头像应用到简历模板中。

### 1.3 产品目标

1. 降低用户制作简历的门槛，让用户通过填写表单即可快速生成结构清晰、排版美观的 PDF 简历。
2. 支持实时预览，用户在填写过程中能即时看到简历最终效果。
3. 提供多模块化内容编辑能力，满足学生求职、实习申请、社招求职、考研复试、项目申报等不同场景。
4. 提供头像优化能力，解决用户头像背景不规范、尺寸不统一、清晰度不足、风格不职业的问题。
5. 后续可拓展 AI 润色、岗位匹配、简历评分、多语言简历、在线投递等能力。

## 2. 背景与问题

### 2.1 用户痛点

当前用户制作简历时普遍存在以下问题：

1. 简历排版门槛较高
   用户需要使用 Word、WPS、Canva 等工具手动排版，容易出现格式混乱、间距不统一、字体不一致等问题。
2. 内容组织不清晰
   学生和初级求职者往往不知道项目经历、工作经历、技能、课程、自我介绍应该怎么写，导致简历内容空泛或重点不突出。
3. PDF 导出不稳定
   使用普通文档工具导出 PDF 时，可能出现字体变化、分页异常、图片错位等问题。
4. 头像处理麻烦
   很多用户没有标准白底/蓝底/红底证件照，也不会使用修图软件处理头像背景、尺寸和清晰度。
5. 模板选择成本高
   市面上模板较多，但用户不知道哪个模板适合自己的岗位和经历类型。
6. 版本管理不方便
   用户可能需要针对不同岗位准备不同版本的简历，例如技术岗、运营岗、考研复试、实习申请等，传统方式管理困难。

### 2.2 产品机会

通过“表单填写 + 实时预览 + 模板选择 + PDF 导出 + 头像优化”的方式，可以将复杂的简历制作流程简化为标准化操作。后续结合 AI 润色和岗位匹配能力，还可以进一步提升简历内容质量。

## 3. 目标用户

### 3.1 核心用户

1. 大学生 / 应届毕业生
   需要制作实习简历、校招简历、考研复试简历、竞赛项目简历。
2. 初级职场人士
   工作 1–3 年，需要快速制作社招简历。
3. 转岗用户
   需要根据目标岗位重新组织项目经历、技能栈和自我介绍。
4. 培训机构 / 就业辅导机构
   需要批量帮助学生生成规范简历。

### 3.2 用户特征

1. 对简历排版和设计不熟悉。
2. 希望快速生成正式、清晰、可投递的 PDF 简历。
3. 希望头像看起来更规范、职业。
4. 需要多版本简历管理。
5. 部分用户希望系统辅助润色内容。

## 5. 产品核心流程

### 5.1 用户主流程

1. 用户进入简历生成页面。
2. 系统默认展示一个简历编辑器页面。
3. 页面左侧为表单编辑区，右侧为实时预览区。
4. 用户依次填写个人信息、教育经历、项目经历、工作经历、技能、课程、自我介绍等内容。
5. 用户上传头像。
6. 用户选择头像优化版本，例如白底、蓝底、红底、职业照风格。
7. 系统生成优化后的头像，用户确认后应用到简历。
8. 用户选择简历模板。
9. 用户查看右侧实时预览。
10. 用户点击“导出 PDF”。
11. 系统生成 PDF 文件。
12. 用户下载简历。

### 5.2 简历编辑流程

1. 新建简历。
2. 选择使用场景：
   - 校招简历
   - 实习简历
   - 社招简历
   - 考研复试简历
   - 项目申报简历
   - 自定义简历
3. 系统根据场景初始化默认模块。
4. 用户填写内容。
5. 用户调整模块顺序。
6. 用户隐藏不需要的模块。
7. 用户切换模板并预览。
8. 保存或导出。

### 5.3 头像优化流程

1. 用户点击头像区域。
2. 上传本地图片。
3. 系统展示裁剪框。
4. 用户调整头像裁剪区域。
5. 用户选择优化类型：
   - 保持原图，仅裁剪
   - 白底证件照
   - 蓝底证件照
   - 红底证件照
   - 职业头像
   - 自然清爽头像
   - 高清修复
6. 系统根据用户选择生成对应提示词。
7. 调用图片生成 / 图片编辑接口。
8. 展示优化结果。
9. 用户确认应用。
10. 头像进入简历预览区。

## 6. 页面结构设计

### 6.1 页面整体布局

页面采用左右分栏结构。

左侧为表单编辑区，右侧为简历预览区。

#### 桌面端布局

- 左侧宽度：40%
- 右侧宽度：60%
- 左侧支持滚动填写
- 右侧固定展示 A4 简历预览
- 顶部提供操作栏

#### 移动端布局

移动端可采用标签页切换：

- 编辑
- 预览
- 模板
- 导出

移动端不强制实现实时左右分屏，但需要保证预览功能可用。

### 6.2 顶部操作栏

顶部操作栏包含：

1. 产品 Logo
2. 简历名称
3. 保存状态
   - 未保存
   - 保存中
   - 已保存
4. 模板选择按钮
5. 预览按钮
6. 导出 PDF 按钮
7. 更多操作
   - 复制简历
   - 重命名
   - 删除
   - 恢复历史版本

### 6.3 左侧表单编辑区

左侧表单采用模块化结构，每个模块可展开、折叠、编辑、删除、排序。

默认模块包括：

1. 个人信息
2. 求职意向
3. 教育经历
4. 主修课程
5. 项目经历
6. 工作经历 / 实习经历
7. 校园经历
8. 竞赛 / 证书 / 荣誉
9. 技能 & 技术栈
10. 自我介绍
11. 自定义模块

### 6.4 右侧预览区

右侧预览区展示 A4 尺寸简历效果。

预览区要求：

1. 内容填写后实时同步。
2. 支持缩放查看。
3. 支持分页提示。
4. 超出一页时提示用户内容过长。
5. 支持切换模板后即时更新。
6. 支持头像实时替换。
7. 支持显示 PDF 导出效果。

## 7. 功能需求

## 7.1 用户系统

### 7.1.1 注册登录

#### 功能说明

用户可以注册账号并登录，以便保存简历数据。

#### 支持方式

MVP 阶段支持：

1. 手机号登录
2. 邮箱登录
3. 验证码登录
4. 游客模式

二期支持：

1. 微信登录
2. Google 登录
3. GitHub 登录

#### 需求说明

1. 用户未登录时也可以创建简历。
2. 游客模式下，简历数据优先保存在本地。
3. 用户登录后，可将本地简历同步至云端。
4. 用户退出登录后，本地缓存不应立即清空，避免数据丢失。

## 7.4 头像上传与优化模块

### 7.4.1 功能说明

用户可以上传头像，并对头像进行裁剪、背景替换、清晰度优化和职业化处理。

### 7.4.2 上传要求

支持格式：

1. JPG
2. PNG
3. WEBP

文件限制：

1. 单张图片大小不超过 10MB。
2. 最小分辨率建议不低于 300 × 300。
3. 超出大小时提示压缩或重新上传。

### 7.4.3 基础处理功能

1. 图片上传
2. 图片预览
3. 图片裁剪
4. 图片旋转
5. 图片缩放
6. 图片居中
7. 恢复原图
8. 删除头像

### 7.4.4 AI 优化类型

用户可勾选以下优化版本：

1. 白底证件照
2. 蓝底证件照
3. 红底证件照
4. 职业商务头像
5. 自然清爽头像
6. 高清修复
7. 去除杂乱背景
8. 提亮肤色
9. 保持本人特征
10. 不改变五官

### 7.4.5 提示词生成逻辑

系统根据用户选择自动拼接提示词。

#### 示例 1：白底证件照

用户选择：

- 白底
- 高清修复
- 保持本人特征
- 不改变五官

系统生成提示词方向：

“将用户上传的人像处理为标准白色背景证件照风格，保持人物真实五官和面部特征不变，去除杂乱背景，提升清晰度和光线自然度，保持正式、干净、适合简历使用的职业形象。”

#### 示例 2：蓝底证件照

“将头像背景更换为标准蓝色证件照背景，保持人物真实身份特征不变，面部自然清晰，光线均匀，服装和发型保持自然整洁，适合简历、报名表和正式资料使用。”

#### 示例 3：职业商务头像

“将用户头像优化为自然职业商务头像，背景简洁干净，人物形象清晰自然，整体风格正式但不过度修饰，保持真实五官，不改变年龄、脸型和身份特征，适合求职简历展示。”

### 7.4.6 生成结果展示

生成后展示：

1. 原图
2. 优化图
3. 对比视图
4. 重新生成
5. 应用到简历
6. 下载头像

### 7.4.7 头像安全与合规要求

1. 不得将用户头像用于训练，除非用户明确授权。
2. 图片生成过程需提示用户：系统仅用于简历头像优化。
3. 不允许生成虚假身份照片。
4. 不应过度改变用户五官、年龄、性别等核心身份特征。
5. 用户可随时删除头像数据。
6. 用户删除简历时，应同步删除相关头像资源。

## 9. 实时预览功能

### 9.1 功能说明

用户填写表单时，右侧简历预览区实时更新。

### 9.2 预览要求

1. 预览尺寸接近 A4 纸张比例。
2. 预览内容与导出 PDF 保持一致。
3. 字体、行距、模块间距应尽量还原导出效果。
4. 支持缩放。
5. 支持分页。
6. 支持超出一页提醒。
7. 支持点击预览区模块后，左侧自动定位到对应表单模块。

### 9.3 交互规则

1. 左侧填写姓名，右侧姓名同步更新。
2. 左侧新增项目经历，右侧立即新增对应内容。
3. 左侧调整模块顺序，右侧同步调整。
4. 左侧隐藏模块，右侧不再展示该模块。
5. 右侧点击模块标题，左侧滚动到对应编辑区域。

## 10. PDF 导出功能

### 10.1 功能说明

用户可将当前简历导出为 PDF 文件。

### 10.2 导出要求

1. PDF 页面尺寸为 A4。
2. 导出效果与预览一致。
3. 支持中文字体。
4. 支持头像高清导出。
5. 支持多页导出。
6. 支持文件命名。
7. 支持导出前预检查。

### 10.3 文件命名规则

默认文件名：

姓名_目标岗位_简历.pdf

示例：

张三_Java后端开发_简历.pdf

如果用户未填写姓名，则使用：

我的简历_20260707.pdf（日期格式为 `yyyyMMdd`）

### 10.4 导出前检查

系统在导出前检查：

1. 是否填写姓名。
2. 是否填写联系方式。
3. 是否存在空模块。
4. 是否存在超出页面范围的内容。
5. 头像是否加载成功。
6. 是否有未保存内容。

### 10.5 导出失败处理

如果导出失败，提示：

“PDF 生成失败，请稍后重试或检查网络连接。”

同时提供：

1. 重新导出
2. 保存草稿
3. 联系客服 / 反馈问题

## 11. AI 辅助功能

### 11.1 MVP 可选功能

MVP 可以只做头像提示词生成，不强制做文本 AI 润色。

### 11.2 二期 AI 文本能力

后续支持：

1. 自我介绍生成
2. 项目经历润色
3. 工作经历润色
4. 技能关键词推荐
5. 根据岗位 JD 优化简历

1. 不虚构经历。
2. 不编造公司、项目、奖项、证书。
3. 不夸大成果。
4. 只在用户提供的事实基础上优化表达。
5. 用户必须确认后才写入简历。

### 11.4 AI 润色交互

1. 用户点击某个模块的“AI 优化”。
2. 系统读取该模块内容。
3. 用户选择优化方向：
   - 更正式
   - 更简洁
   - 更适合技术岗
   - 更适合运营岗
   - 更突出成果
   - 更适合学生简历
4. 系统生成优化建议。
5. 用户选择：
   - 应用
   - 重新生成
   - 复制
   - 放弃

### 13.3 分享权限

1. 公开链接

## 14. 异常场景

### 14.1 表单填写异常

1. 用户未填写姓名
   提示：“建议填写姓名，便于生成正式简历。”
2. 用户未填写联系方式
   提示：“简历中至少需要填写手机号或邮箱。”
3. 用户填写 URL 格式错误
   提示：“请输入正确的网址格式。”
4. 用户填写内容过长
   提示：“当前内容较长，可能导致简历超出一页。”

### 14.2 图片上传异常

1. 图片格式不支持
   提示：“请上传 JPG、PNG 或 WEBP 格式图片。”
2. 图片过大
   提示：“图片大小不能超过 10MB。”
3. 图片加载失败
   提示：“图片加载失败，请重新上传。”
4. AI 优化失败
   提示：“头像优化失败，请稍后重试或使用原图。”

### 14.3 PDF 导出异常

1. 网络异常
   提示：“网络异常，PDF 生成失败。”
2. 图片资源未加载
   提示：“头像加载失败，请重新生成后导出。”
3. 内容超出页面
   提示：“当前简历内容较长，可能导出为多页。”

## 22. 风险与注意事项

### 22.1 技术风险

1. PDF 导出效果与页面预览不一致。
2. 中文字体在 PDF 中显示异常。
3. 图片优化耗时较长。
4. 多页简历分页控制复杂。
5. 模板系统扩展难度较高。
6. 实时预览在复杂简历下可能卡顿。

### 22.2 产品风险

1. 用户填写内容质量较差，生成简历仍不理想。
2. 模板过少会影响用户体验。
3. AI 润色如果虚构内容，会带来信任问题。
4. 头像优化如果过度改变本人特征，可能引发争议。
5. 简历中包含隐私信息，数据安全要求较高。

### 22.3 规避策略

1. MVP 阶段优先保证 PDF 导出稳定。
2. 模板数量不必过多，但必须精致。
3. AI 润色必须基于用户原始内容，不虚构经历。
4. 头像优化强调“保持本人真实特征”。
5. 简历数据和头像数据必须支持用户删除。
6. 导出前增加预检查机制。

## 23. 成功标准

MVP 上线后，可用以下指标判断产品是否成功：

1. 用户可以在 10 分钟内完成一份基础简历。
2. PDF 导出成功率达到 95% 以上。
3. 用户填写后预览无明显错位。
4. 用户上传头像后可成功应用到简历。
5. 用户导出的 PDF 可直接用于求职投递。
6. 首批用户反馈中，排版清晰度、使用便利性、导出稳定性评价较好。

------

## 24. 总结

本产品的核心价值是将简历制作从“手动排版”转变为“结构化填写 + 实时预览 + 一键导出”。MVP 阶段应优先保证简历编辑、模板预览、头像上传和 PDF 导出的基础闭环稳定可用；二期再逐步加入 AI 润色、头像优化、岗位匹配、简历评分和多版本管理等能力。

产品设计上应始终坚持三个原则：

1. 内容真实，不虚构用户经历。
2. 排版稳定，导出效果和预览一致。
3. 操作简单，让普通用户无需设计经验也能生成正式简历。
